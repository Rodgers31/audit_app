# Approved admin visual direction

[Open the preserved HTML concept](approved-admin-concept.html) in a browser to review the earlier visual design. It is an archived, standalone **planning mock-up**, not an application component and not connected to an API or social account. Buttons and sample receipts are simulated; sample financial content is illustrative.

The user approved the admin UI direction in the conversation. Keep the existing AuditGava admin shell, add Social navigation, use the queue/editor/preview pattern, show evidence alongside content and keep destination-specific outcomes visible.

The HTML preserves the prior artifact as-is. Its original visualization host supplied some presentation helpers/icons; those may not render identically when opened standalone. It references Google Fonts. The [engineering blueprint](../ENGINEERING_BLUEPRINT.md) supplies the authoritative current wireframes and behavior, including the first-class manual composer, media uploads, schedule controls, mobile layout and later refinements not all present in this earlier concept.

Do not treat mock actions, displayed accounts, API eligibility, exact token health or example delivery states as real integrations. Do not copy illustrative content into production.
