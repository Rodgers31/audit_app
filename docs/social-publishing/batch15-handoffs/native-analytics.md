## Implemented behavior

- Real native Meta v26 GET insights transport, reusing existing MetaHTTP private app-secret proof, bearer headers, encrypted credential envelopes, generation/parent-generation checks and unsettled renewal refusal. Facebook uses the Page token; Instagram with Facebook Login uses the parent Facebook User token, as required by the current docs. No provider request runs at import, startup, capability inspection or on a background timer.
- Explicit one-target `backend/social_metrics.py` operator. Collection requires both its command switch and configured runtime enabled/free-access/operational attestations. `CollectionCommand` binds account, credential and parent IDs/versions, immutable payload hash, remote ID and source/config/runtime-generation hash. Preparation additionally binds the exact transport request; changed provider/account/target/remote/bounds are refused before wire access. Material is checked again in the observation commit transaction; changed authorization discards observations and durably marks failure.
- Existing durable collection reservation is committed before a read. Existing hourly/account and UTC-day quotas include failed/interrupted reads. 20 observations, 32KiB wire and normalized response bounds, 10-second outer process deadline, no redirects or wire retries. Existing spawned-process session/watchdog/descendant cleanup is retained. Interrupted parent execution leaves its reservation in history; explicit restart cannot retry inside quota. No automatic recovery/resend or lease clearing.
- Provider metric names/API version, account/platform/remote identity, integer values, units, lifetime period, optional actual end_time, observation time, one-hour freshness policy, and unavailable/null remain distinct. The provider does not supply an exact lifetime start date: nullable dates are intentional. Empty valid data becomes unavailable observations, never zero. Unknown/malformed/duplicate metrics and hostile numbers refuse.
- Capability API now inspects the actual enabled native runtime and existing encrypted, scoped, current-generation published targets. A fixture registry or flag alone cannot advertise availability. Check is bounded to 50 sorted public targets and explicitly explains that bound when no eligible target is found. Stored observations remain readable while collection is disabled. Existing frontend decoder/display accepts unknown lifetime dates and renders them explicitly.
- Native registry supports Facebook (`post_media_view`, `post_total_media_view_unique`, `post_clicks`) and Instagram (`views`, `reach`, `saved`, `shares`, `total_interactions`) only. X always remains zero-spend blocked. Threads/TikTok have no invented adapter/access. No provider permission grant or credential change is performed.

## Configuration and one-shot operator

Default `SOCIAL_ANALYTICS_ENABLED=false`. `configured_runtime()` does not read the key ring while disabled. Enabling in a separately authorized environment requires `SOCIAL_ANALYTICS_ENABLED=true`, `SOCIAL_ANALYTICS_OPERATIONAL_GATES_VERIFIED=true`, `SOCIAL_ANALYTICS_FREE_ACCESS_VERIFIED=true`, `SOCIAL_ANALYTICS_PLATFORMS=facebook,instagram` (or one supported platform), and positive `SOCIAL_ANALYTICS_GENERATION`. It reuses existing `META_APP_SECRET`, `SOCIAL_CREDENTIAL_ACTIVE_KEY_VERSION`, `SOCIAL_CREDENTIAL_KEYS`; no dotenv, new keys, grants or provider reads are involved. Increment runtime generation whenever configuration/material/access attestations change; regenerate command runtime hash using `configured_runtime().fingerprint()`.

An operator prepares a <=4096-byte JSON `CollectionCommand` containing the exact existing IDs/versions/hash/remote/runtime values, with no tokens. In an independently authorized environment only:

```sh
PYTHONPATH=backend python backend/social_metrics.py TARGET_UUID --authorization /absolute/path/command.json --enable-native-collection
```

The operator intentionally offers no bulk scan or scheduled mode. CLI refuses nonzero with a fixed safe message on failure. Durable reservation history is authoritative; do not blindly retry a failed command. There is no mutating collection HTTP endpoint; admin HTTP exposes capability and stored observations, and the operator is the explicit collection entrypoint. Global/account publishing and uploads are independent and need no enablement for metrics.
