Old mutation history cannot exhaust read capacity. |

Successful/in-flight targets are never reposted. |

Only the existing synchronous psycopg2 PostgreSQL driver is accepted. Four negative configuration tests failed before the fix; CLI error output is sanitized. |

| Next OAuth work sounds complete | Valid wording ambiguity | The ledger now explicitly states that OAuth/credentials are future work, not implemented or tested by batch 1. |
