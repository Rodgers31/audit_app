## Manual public-outcome authority

Actual administrator-only, no-store routes under `/api/v1/admin/social/targets/{target_id}/meta-reels/` expose `GET public-proof`, `POST public-proof` and `POST record-existing`. These are included in the existing social router. The first administrator proposes fresh anonymous-public and separate owner-identity capture packets. A different administrator independently inspects and admits the same exact Reel using two more unused custody packets. All four packet hashes/references are independent; expiry is thirty minutes from the first observation. Private, restricted, unavailable, partially observable or unverifiable media cannot be recorded.

The service binds exact platform/API product, numeric owner, approved revision/payload/hash, complete caption, source MP4 hash, known final remote identity, checkpoint, publication version, target state/epoch and durable public dispatch permit. It rejects unfinished attempts, even expired retained leases, reused packets, contradictory IDs, container IDs presented as Instagram posts, duplicate remote identities across the same platform/owner and stale proposal state. It checks stored audit/idempotency receipt values and settlement readback, including deferred PostgreSQL constraints; failure rolls back evidence, outcome and account hold together.

Admission changes the selected target to Published with `meta-reels-two-admin-public-v1`, increments publication version and clears only its exact reconciliation hold. Attempts, checkpoints, remote references, submit counts, siblings, controls and credentials are preserved. The operator command never calls a provider or resends media. A replay returns the stored result; changed input under the same key is refused.

Public copies may be transcoded; byte identity with the approved original is not required or claimed. Administrators compare the entire rendered scene/audio sequence to the approved source and retain the public/identity captures in already approved custody. Hash/UUID strings and narratives are auditable assertions, not independently machine-verified public visibility. Real custody suitability, independent operator competence and permitted access remain operational acceptance requirements. No new storage service or evidence upload was added.
