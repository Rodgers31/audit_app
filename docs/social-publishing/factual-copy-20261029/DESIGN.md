# Versioned deterministic financial copy

This increment improves the existing shared renderer for qualified pending-bills, national-budget and KRA financial observations. It uses no model, paid service, source acquisition or new generation route. It is based on the bounded cohort repair in draft PR #851; publication and production admission remain outside this increment.

## Editorial rules

The loaded brand, voice and social-writing guidance is applied as factual, nonpartisan civic reporting: one clear opening figure; exact amounts with readable grouping; reporting period and scope; visible uncertainty; named publisher; one useful invitation to explore the source. No adequate human-authored corpus was established, so this is not claimed as a validated imitation of a personal voice. No engagement guarantees, invented urgency, allegations, fiscal interpretation, percentage comparisons or social-reach claims are added.

`KSh` is the display label for the supplied `KES` unit. Decimal formatting never uses a float, rounds, rescales a value or changes the stored evidence. Existing source scales remain explicit. A national revised gross budget is distinguished from actual expenditure. KRA departmental scope, including agency levies where provided, is retained. Pending-bills stock uses the source-bound date and keeps the Grand Total completeness limit and all reader notes. A narrower pending-bills subcategory stays in the headline.

The new template accepts the supported actual-KES reporting bases. Unknown bases or conflicting scopes refuse with an explicit unresolved-template outcome. Known caveats have approved plain wording; additional notes on a recognized basis remain visible verbatim. Unvalidated model copies are revalidated before producing financial copy. Correction markers and unresolved placeholders remain subject to explicit checks.

## Version and authority boundaries

New native financial drafts record `financial-v2`. `factual-v1` remains reproducible for saved financial revisions, and existing non-native fact/report templates keep their original versions and text. The advisory comparison reads the saved revision's exact metadata rather than treating old template text as a human edit. Unknown/missing versions and mismatched metadata refuse; canonical JSON comparison preserves boolean/integer distinctions.

Source observations, semantic fingerprints, cursor decisions, event evidence, worker-authority checks, immutable revisions, explicit attestation and publication gates remain in place. Changing a template does not make unchanged source data a new event or rewrite a saved draft. Financial content continues to require human review; automation categories and policy authority are unchanged. No flags, scheduled jobs, providers or workers are enabled.

The examples in `EXAMPLES.md` and `examples.json` are output from the actual renderer in an offline Docker process, with closed fixture flags. They are not source-qualification or production acceptance receipts.
