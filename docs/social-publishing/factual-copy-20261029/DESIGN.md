# Versioned deterministic financial copy

This increment improves the existing shared renderer for qualified pending-bills, national-budget and KRA financial observations. The follow-up in [UNIVERSAL_COPY.md](UNIVERSAL_COPY.md) extends readable wording to every existing general-fact category and neutral report family across county and national entities. It uses no model, paid service, source acquisition or new generation route. It is based on the bounded cohort repair in draft PR #851; publication and production admission remain outside this increment.

## Editorial rules

The loaded brand, voice and social-writing guidance is applied as factual, nonpartisan civic reporting: one clear opening figure; compact amounts with explicit approximation; reporting period and scope; visible uncertainty; named publisher; one useful invitation to explore the source. No adequate human-authored corpus was established, so this is not claimed as a validated imitation of a personal voice. No engagement guarantees, invented urgency, allegations, fiscal interpretation, percentage comparisons or social-reach claims are added.

`KSh` is the display label for the supplied `KES` unit. The financial-v3 display converts source units, thousands, millions and billions into the same KES amount using Decimal in a local precision context. It uses thousand/million/billion labels and rounds to one decimal with half-up rounding. Inexact displays begin with “about”; exact displays do not. Carry promotes 999.95 million to about 1 billion. Values below 1,000 remain exact. Source cells, scales, fingerprints and stored evidence are unchanged; no float enters copy formatting. A national revised gross budget is distinguished from actual expenditure. KRA departmental scope, including agency levies where provided, is retained. Pending-bills stock uses the source-bound date and keeps the Grand Total completeness limit and all reader notes. A narrower pending-bills subcategory stays in the headline.

The financial template accepts the supported actual-KES reporting bases. Unknown bases or conflicting scopes refuse with an explicit unresolved-template outcome. Known caveats have approved plain wording; additional notes on a recognized basis remain visible verbatim. Unvalidated model copies are revalidated before producing financial copy. Correction markers and unresolved placeholders remain subject to explicit checks.

## Version and authority boundaries

New native financial drafts record `financial-v3`. `factual-v1` and `financial-v2` remain reproducible for saved financial revisions, and saved non-native fact/report revisions keep their pinned versions and text. New general-fact/report/catalogue drafts use their V2 wording described in UNIVERSAL_COPY.md. The advisory comparison reads the saved revision's exact metadata rather than treating old template text as a human edit. Unknown/missing versions and mismatched metadata refuse; canonical JSON comparison preserves boolean/integer distinctions.

Source observations, semantic fingerprints, cursor decisions, event evidence, worker-authority checks, immutable revisions, explicit attestation and publication gates remain in place. Changing a template does not make unchanged source data a new event or rewrite a saved draft. Financial content continues to require human review; automation categories and policy authority are unchanged. No flags, scheduled jobs, providers or workers are enabled.

The examples in `EXAMPLES.md` and `examples.json` are output from the actual renderer in an offline Docker process, with closed fixture flags. They are not source-qualification or production acceptance receipts.
