The exact legacy package sources and their distributed file hashes were preserved under `baseline/`. `legacy-caller-inventory.json` identifies all 15 plugin files. The same harness will execute final installed repaired bytes and compare diagnostics, rather than only checking that the plugins can load.

`baseline-effective-configs.json` captures complete effective configurations for all 360 current Next lint source targets plus six extension probes: 366 paths, two unique effective configurations, 54 configured/46 enabled rules, including both local rules at error severity. It binds `.eslintrc.json`, the two local rule implementations and their plugin index. This supports a complete configuration comparison after migration; rule-count equality alone is insufficient.

Cache compatibility was executed on actual file-entry-cache 6 and the exact ESLint 8 LintResultCache source. Baseline flat-cache3/rimraf3 and candidate flat-cache3/rimraf6 each pass nine controls: metadata/content cache roundtrip, config/content invalidation, same-length changed content with restored mtime under checksum mode, malformed cache recomputation, literal metachar filenames, output-bearing cache exclusion, nested directory deletion and directory symlink target preservation. Controls are grouped and overlap. The alternative flat-cache4.0.1 passes normal cache cases but fails nested directory deletion and follows a directory symlink, removing its owned target sentinel before failing. Prefer scoped rimraf6. See `cache-compatibility-final-results.json`, `cache_compatibility_verified.cjs` and the exact command receipt. No deletion touched candidate paths.

The transition intentionally stops using the old regex mechanism. It cannot promise equality for every arbitrary future glob option. The independently executed 260-pair `makeRe` versus modern `match` matrix shows differences for dot files, zero-directory globstars, extglobs, empty/comment patterns and trailing separators. For example old `makeRe('pkg/**').test('pkg/.hidden')` is true while modern matching is false. Existing effective configurations do not enable no-internal-modules; preserve the exact current effective policy and demonstrate ordinary enabled/disabled outcomes. Record modern behavior for future option changes instead of restoring the vulnerable regex API or claiming universal historical equivalence.
