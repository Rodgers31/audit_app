# Lane lessons for coordinator-owned shared skills

1. Freeze/archive the executable evidence generator before the first run,
   including formatting. The first two local receipts here preceded Black
   formatting and lack preserved generator bytes. Their records remain
   historical and are not used for behavioral acceptance; the valid red and
   matching green use the same generator and same fixture bytes.
2. Validate synthetic database NOT NULL operands and citation locators before
   calling a failing API fixture behavioral red. The first page locator and
   national/timeline operands were invalid. Separate these failures from the
   helper's real projection/nonfinite leaks rather than counting every failure
   as an issue reproduction.
3. Removing a truthy forecast fallback can expose downstream absence paths.
   The unchanged national-debt code returned zero for missing GDP; the
   sustainability no-data branch hid the forecast series. Execute each real
   caller with the newly absent helper and keep projection contracts distinct.
4. Preserve vintage selection semantics separately from actual selection.
   Country-wide max-vintage differs from indicator-specific max-vintage; changing
   both would silently import older actuals into a newer publication snapshot.
5. Check computed results as well as operands. A finite positive GDP of
   `1e-320` still produces an infinite floating-point quotient. Validate before
   publication, including nested response fields.
6. Evidence acceptance needs complete inputs, required outputs, and actual
   executed-case counts. Comparing only listed hashes or declared XML totals
   lets omissions pass; execute refusal controls in normal Python and `-O`.
7. Deduplicate cohort selections and compare actual case identities before
   reporting counts. Preserve the original selection and explain corrected
   counts rather than rewriting its historical record.

Shared skill files are read-only to this author; these are proposals/evidence,
not changes to common policy.
