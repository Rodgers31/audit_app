# Source transport and debt coverage contract v1

Fixed baseline: 0315cd8220e2a3ede99dbf92389dd4769f84aa47. This local patch does not authorize source adoption or release.

CoG current governors: https://cog.go.ke/current-governors/ ; deputies: https://cog.go.ke/current-deputy-governors/ . Both are HTML GET bodies, HTTP200, verified HTTPS, redirects limited to cog.go.ke/www.cog.go.ke. Each page has a45-second total budget,4MiB cumulative decoded-body cap and configured transient attempt/backoff limits. Main-thread POSIX interval timing preserves any earlier CLI domain alarm. Unsupported thread/platform callers refuse. Normal certificate verification and existing verified-chain completion remain enabled. DNS/connect/body interruptions may recover; certificate authority/hostname/expiry/chain refusals do not retry as progress. The timer interrupts the Python-visible blocking operation; it does not establish remote resolver cancellation or serving-host orphan cleanup.

Governors require47 distinct known counties and47 distinct people, paired inside one `div.captions` card. Identical repeated slider cards remain supported; conflicting duplicates, unknown counties, malformed cards and challenge bodies refuse. Deputies retain the existing40–47 completeness floor and vacancy/elevation rules. Governor acquisition failure writes no names or source timestamps. `metadata.source_status` explicitly records unavailable/partial/live, fixture_used=false, retained-name counts and known age bounds. Unknown/future/unparseable stored timestamps have unknown age. The shared fixture freshness mode remains unchanged pending workflow-owner terminology changes; no fixture file is read by this domain. Deputy failure is partial and retains prior deputies except a known same-person governor/deputy conflict. Successful pages retain the existing response-receipt envelope separately for each document; no financial authority is inferred from that envelope.

PDF interfaces remain compatible: download_to_file/get_or_download_pdf/download_receipt. Trust refusals raise ConnectError, not PdfDownloadIncomplete. A real partial may persist for bounded transient recovery; an oversized retained partial/cache entry cannot bypass caller limits. Resumed206 requires the requested Content-Range start. Assembled or replayed partials do not fabricate a new full-response acquisition receipt. PDF magic/EOF checks establish format-shaped completeness, not source-content acceptance. Cached bytes must agree with any declared size/hash and finite creation/TTL bounds.

Debt diagnostics are `metadata.year_coverage`, contract `debt-calendar-observation-coverage-v1`, with per-year external/domestic/total/GDP entries. Each identifies measure, KES units, actual/current_prices basis, calendar year, monthly stock locator, acquired_at, source URL/digest and unknown publication/vintage dates. States: observed_this_run (accepted persisted receipt/value matches current acquisition and existing qualifier verifies), observed_unretained (accepted current but unqualified retention), retained_qualified (existing qualifier verifies historical stored evidence), unqualified. A refused incoming receipt cannot refresh a retained row's status or date. Ratios remain qualified derived pairs only through the existing qualifier. A monthly stock is not labelled a year-end stock unless its source locator is December. No source-publication date is inferred from acquisition time. Missing annual GDP in an unfinished year is `annual_period_not_ended`; other missing observations are `not_observed_in_selected_source`, never proof of worldwide source absence or publication delay. Unknown source vintage remains null and requires edition-specific qualification for adoption.

Canonical debt sources remain the configured/discovered official CBK Statistical Bulletin Table4.1.3 (listing https://www.centralbank.go.ke/releases/statistical-bulletin/ ) and World Bank GDP API https://api.worldbank.org/v2/country/KEN/indicator/NY.GDP.MKTP.CN?format=json&per_page=100 . Exact bulletin URL/digest comes from each observed response, never from a guessed alternate. CBK FY labels only locate monthly rows; the calendar month is retained. Future monthly actuals refuse. Missing historical stock remains retained-qualified only if the existing financial qualifier independently verifies it; no forecast, redemption series, county borrowing or county balance is admitted. Aggregate debt refresh remains partial when only4/14 years refresh; per-year diagnostics do not relax it.

Integration requests belong to workflow/financial owners: display these distinctions, probe selected exact sources within the same bounds, preserve zero/error refusal, and qualify exact public readers before adoption. No workflow, global mode, publication gate, runtime lock or production state is changed here.
