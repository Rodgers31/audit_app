## OAG acquisition repair

The ordinary OAG refresh reuses cached PDFs without an original persisted HTTP
receipt. Local bytes and sidecar JSON cannot safely bootstrap report authority.
The refused path never reaches the RSS catalogue loader. Separately, broad
discovery has upstream HTML/API/PDF warnings; a successful findings refresh
cannot substitute for exact report acceptance.

All four exact PDFs already exist in the configured private R2 store: actual
GET/readback verifies their SHA256 and sizes, totaling82,207,182bytes. The gap is
original HTTP/source authority, not loss of those objects. A fresh capture of
the same bytes reuses their content-addressed objects; it needs no additional
PDF storage, quota increase or new service. The current64MiB per-blob ceiling
is sufficient. Byte presence alone grants no native report authority.

The new manual workflow choice `oag-combined-catalogue-20261101` selects only
audits, live mode, no bootstrap, no reconciliation repair and no pending-bills
reacquisition. It passes the exact hash-pinned four-edition manifest to the
existing CLI/handler/loader boundary. The selected PDFs are FY2023/24 and
FY2022/23 county executive and assembly volumes; their hashes and page counts
match the previously reviewed genuine editions. This is an explicit finite
scope, not a discovery completeness claim.

For that manual choice only, the existing runner omits PDF cache restore/save
and the CLI child gets PDF cache TTL0. The ordinary nightly cache, schedules,
source rules, generation controls, providers, resources and quotas are unchanged.
Fresh HTTP capture, durable byte readback, exact current official RSS scope and
the existing native report writer/readers remain mandatory. A catalogue date
must remain a catalogue date; no publication day is inferred.

The scoped extraction guard also distinguishes canonical acquisition/report
metadata from findings. Historical local-byte, missing-byte and conflict
receipts remain non-authoritative metadata. Unknown/malformed/misnamed records
refuse; at least one genuine finding extraction and all existing FY, institution
and artifact checks are still required. Only guard fields are projected, with a
bounded auxiliary inventory; full findings and receipt observation payloads
are not transferred again. New receipts identify the actual manifest hash;
the legacy adopted-volume caller permits only its unchanged exact five-edition
inventory. One-shot iterators and mismatched/new packets cannot emit a false
legacy receipt.
