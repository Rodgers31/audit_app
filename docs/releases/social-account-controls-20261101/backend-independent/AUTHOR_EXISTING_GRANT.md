# Existing Meta grant verification implementation

Implemented `POST /api/v1/admin/social/accounts/{account_id}/verify-publishing-access`. The strict body contains `expected_controls_version`, `expected_state` and `reason`, with an idempotency UUID header. It returns the existing account publishing DTO with publishing still false, the next controls version, a changed monotonic state token and verified enable availability. Enabling account consent remains a separate human action.

The command uses saved User/Page grants through the shared bounded Meta discovery parser, without OAuth exchange or publication calls. It verifies exact Page/linked professional Instagram identity, owner, permissions and Page tasks. Actual injected native adapter/operator gates must be accepted. Database transactions end before provider reads; final controls/account/credential locks fence the full snapshot. Stored scopes, credential envelopes and versions remain intact. Newly shorter expiry metadata requires reconnect. Privacy uncertainty blocks proof and consent rather than being reindexed or cleared by this command.

Final normal and optimized executions each passed **199 tests with zero failures/errors/skips** on unchanged source hashes: 43 authored proof cases, 143 existing connection compatibility cases, nine independent account privacy cases and four actual migrated PostgreSQL race/deferred-write cases. Full XML/stdout are `saved-grant-final-normal.*` and `saved-grant-final-optimized.*`. The exact file hashes, split, contract, boundaries and historical red receipts are in `AUTHOR_EXISTING_GRANT.json`.

Missing route404, privacy before/during reads, absent reader with retained namespace, malformed platform policy, and suppressed proof metadata/audit were observed red before repair. Independent review also led to the separate consent privacy guard. This agent independently reproduced its owner-inventory overflow edge; its owner repaired that false empty result. The final guard supplement is approved: matching and unknown requests block, complete indexed unrelated subjects and foreign apps remain usable, stale intents conflict, pause preserves retained uncertainty, and guard reads exclude ciphertext. A PostgreSQL deferred request inserted during receipt settlement rejects and rolls back consent, audit and receipt.

The disposable PostgreSQL container is removed. All Graph traffic used explicit test transports, with no live provider, production database, upload, publication, worker or activation action. This is local code acceptance; it does not certify live credentials or production readiness.
