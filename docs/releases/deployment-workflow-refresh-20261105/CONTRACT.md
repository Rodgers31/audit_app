## Signed refresh v2

Requests use the existing REVALIDATE_SECRET and HMAC-SHA256 of exact bytes. Every nightly request carries protocol, timestamp, nonce and exact source/plan/schema/run/attempt. Backend and frontend return a raw-byte response HMAC in x-revalidate-response-signature, the original request digest, fresh timestamp and the same context. The workflow refuses unsigned, malformed, stale, duplicate-key, wrong-source or mismatched receipts.

Backend invalidation is followed by actual kernel-derived web-process census and original-generation adoption from every worker. PID plus kernel start ticks prevent PID reuse. Supported topology is a Gunicorn master with its recognized direct workers, or a proven PID1 single-Uvicorn container; unknown supervisors, independently supervised Uvicorn peers, process churn and unreadable kernel evidence refuse. Kernel TCP listeners and descriptor holders corroborate the actual serving ports, including distinct SO_REUSEPORT socket inodes; another master or custom hidden listener cannot be omitted.
